# Bawal Tech Office

Daily office task manager for **Bawal Tech Media**, in the brand's yellow, black and white style.

Open `index.html` in any browser. You don't need to install or build anything.

## Features
- **Dashboard**: greeting, a Start/End Day work log with hours worked, today's stats, today's tasks with checkboxes, a progress ring, upcoming content, quick links to AI tools, a focus timer (25/50/5 min) and a quick note box.
- **Tasks Board**: To Do / In Progress / Done columns with drag and drop, categories (Content Creation, Video Editing, AI Tool Guides…), priority levels, due dates, search and filters.
- **Content Planner**: a weekly calendar for Reels, Shorts, YouTube videos, posts and stories, with a status for each (idea → scripting → shooting → editing → scheduled → published).
- **Notes**: colourful sticky notes for ideas and reminders.
- Light and dark themes, and a mobile-friendly layout.

All data is saved in your browser's localStorage, on your device only.
